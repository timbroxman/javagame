# Инструкция по добавлению звуков в игру

## Расположение файлов

Все звуковые файлы должны быть размещены в папке: **`assets/sounds/`**

## Текущие звуковые файлы

- `background_music.mp3` - фоновая музыка игры
- `destroy.mp3` - звук взрыва/уничтожения
- `shoot.mp3` - звук выстрела

## Рекомендуемые дополнительные звуки

Для улучшения игрового опыта можно добавить следующие звуковые файлы:

1. **bonus.mp3** - звук получения бонуса
   - Используется при сборе бонусов (здоровье, щит, ускоренная стрельба, мультишот)
   - Рекомендуемый формат: короткий позитивный звук (0.5-1 секунда)

2. **damage.mp3** - звук получения урона
   - Используется при попадании по кораблю игрока
   - Рекомендуемый формат: короткий негативный звук (0.3-0.7 секунды)

3. **button_click.mp3** - звук нажатия кнопки
   - Используется при нажатии любых кнопок в меню и настройках
   - Рекомендуемый формат: очень короткий клик (0.1-0.3 секунды)

4. **game_over.mp3** - звук окончания игры
   - Используется при завершении игры (когда корабль уничтожен)
   - Рекомендуемый формат: драматичный звук (1-2 секунды)

5. **boss_spawn.mp3** - звук появления босса
   - Используется при появлении босса на экране
   - Рекомендуемый формат: впечатляющий звук (1-2 секунды)

## Как добавить новые звуки

1. Поместите звуковой файл в папку `assets/sounds/`
2. Обновите путь в файле `core/src/ru/samsung/gamestudio/GameResources.java`:
   ```java
   public static final String BONUS_SOUND_PATH = "sounds/bonus.mp3";
   ```
3. Перезапустите игру

## Форматы файлов

Поддерживаемые форматы:
- **.mp3** - рекомендуется (хорошее сжатие)
- **.ogg** - альтернатива (лучшее качество при том же размере)
- **.wav** - не рекомендуется (большой размер файла)

## Требования к файлам

- Размер файла: желательно не более 500KB для звуков, 2-5MB для музыки
- Частота дискретизации: 44.1 kHz или 22.05 kHz
- Битрейт: 128 kbps для музыки, 64-96 kbps для звуков

## Примечание

В настоящее время все дополнительные звуки используют существующие файлы (`shoot.mp3` и `destroy.mp3`) как временное решение. После добавления отдельных файлов просто обновите пути в `GameResources.java`.
