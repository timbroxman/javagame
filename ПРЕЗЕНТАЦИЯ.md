# Презентация проекта
## Space Defender

---

## 1. Идея проекта

**Space Defender** — это мобильная космическая аркадная игра в жанре shoot'em up (вертикальный скролл-шутер), разработанная на фреймворке LibGDX.

### Концепция:
- Игрок управляет космическим кораблём, защищающим космос от врагов и мусора
- Динамичный геймплей с постепенно возрастающей сложностью
- Система бонусов и комбо для повышения вовлечённости
- Физика на основе Box2D для реалистичных столкновений

### Целевая аудитория:
- Мобильные геймеры (Android)
- Любители аркадных игр
- Возрастная категория: 12+

## 4. Функционал проекта

### 4.1. Игровая механика

#### Управление:
- **Тач-контролы**: управление кораблём касанием экрана
- **Автоматическая стрельба**: корабль стреляет автоматически с интервалом
- **Физика движения**: реалистичное движение с инерцией через Box2D

#### Боевая система:
- **Стрельба**: автоматическая стрельба с кулдауном 1 секунда
- **Мультишот**: бонус для стрельбы 3 пулями одновременно
- **Урон**: 1 урон за попадание (для врагов с несколькими жизнями)

### 4.2. Типы врагов

1. **FAST** — быстрый враг (1 жизнь, высокая скорость)
2. **NORMAL** — обычный враг (1 жизнь, средняя скорость)
3. **SLOW** — медленный враг (2 жизни, низкая скорость)
4. **TANK** — танк (3 жизни, очень низкая скорость)
5. **BOSS** — босс (5 жизней, большой размер, появляется каждые 60 секунд)

#### Паттерны движения врагов:
- Синусоидальное движение (волна)
- Зигзагообразное движение
- Движение по кругу
- Движение с ускорением/замедлением
- Прямолинейное движение

### 4.3. Система бонусов

1. **HEALTH** — дополнительная жизнь (до максимума 3)
2. **RAPIDFIRE** — ускорение стрельбы (10 секунд)
3. **SHIELD** — временная неуязвимость (8 секунд)
4. **MULTISHOT** — стрельба 3 пулями одновременно (временный эффект)

### 4.4. Система прогрессии

#### Уровни сложности:
- Уровень увеличивается каждые 30 секунд игры
- С ростом уровня:
  - Увеличивается частота появления врагов
  - Появляются более сложные типы врагов
  - Увеличивается вероятность появления боссов

#### Система комбо:
- Комбо активируется при уничтожении врагов в течение 3 секунд
- Множитель очков:
  - 5+ уничтожений → x2
  - 10+ уничтожений → x3
  - 20+ уничтожений → x4
  - 30+ уничтожений → x5 (максимум)

#### Подсчёт очков:
- Базовые очки за время игры
- Бонусные очки за уничтожение врагов (с учётом комбо)
- Штраф 10% за пропущенный мусор

### 4.5. Визуальные эффекты

- **Система частиц**: взрывы, искры, дым
- **Тряска камеры**: при получении урона
- **Экранные эффекты**: затемнение при низком здоровье
- **Анимации**: пульсация бонусов, вращение объектов
- **Полоски здоровья**: для врагов с несколькими жизнями

### 4.6. Интерфейс

#### Главное меню:
- Кнопка "Start" — начало игры
- Кнопка "Settings" — настройки
- Кнопка "Exit" — выход

#### Игровой экран:
- Отображение счёта
- Индикатор жизней
- Отображение уровня сложности
- Индикаторы активных бонусов
- Кнопка паузы

#### Экран паузы:
- Кнопка "Continue" — продолжить игру
- Кнопка "Home" — вернуться в меню

#### Экран окончания игры:
- Таблица рекордов (топ-10)
- Кнопка "Home" — вернуться в меню

### 4.7. Система сохранений

- Сохранение таблицы рекордов (топ-10)
- Сохранение настроек звука
- Локальное хранение данных через SharedPreferences (Android)

## 5. Технические особенности

### 5.1. Технологический стек

- **Язык программирования**: Java 8
- **Игровой фреймворк**: LibGDX 1.12.1
- **Физический движок**: Box2D
- **Система сборки**: Gradle 8.5
- **Платформы**: Android, Desktop (Windows/Linux/macOS)

### 5.2. Архитектура проекта

#### Структура модулей:
```
├── core/          # Общая логика игры (кроссплатформенная)
├── android/       # Android-специфичный код
└── desktop/       # Desktop-специфичный код
```

#### Основные компоненты:

**Объекты игры:**
- `GameObject` — базовый класс для всех игровых объектов
- `ShipObject` — корабль игрока
- `EnemyShipObject` — вражеские корабли (5 типов)
- `BulletObject` / `EnemyBulletObject` — пули
- `TrashObject` — космический мусор
- `BonusObject` — бонусы (4 типа)

**Экраны:**
- `MenuScreen` — главное меню
- `GameScreen` — игровой экран
- `SettingsScreen` — экран настроек

**Менеджеры:**
- `ContactManager` — обработка столкновений Box2D
- `AudioManager` — управление звуком
- `MemoryManager` — сохранение/загрузка данных

**Эффекты:**
- `ParticleSystem` — система частиц
- `CameraShake` — тряска камеры
- `ScreenEffects` — экранные эффекты

### 5.3. Физика и производительность

#### Box2D настройки:
- Частота обновления: 60 FPS
- Итерации скорости: 6
- Итерации позиции: 6
- Масштаб: 0.05 (для точности физики)

#### Оптимизация:
- Использование SpriteBatch для эффективной отрисовки
- Управление памятью через dispose() методы
- Оптимизация системы частиц
- Эффективное использование текстур

### 5.4. Особенности реализации

#### Система столкновений:
- Использование битовых масок для категорий объектов
- Раздельная обработка столкновений разных типов
- Оптимизированная система контактов через ContactListener

#### Система спавна:
- Динамическое увеличение частоты спавна
- Экспоненциальное уменьшение кулдауна со временем
- Вероятностная система выбора типов врагов

#### Система бонусов:
- Временные эффекты с автоматическим истечением
- Визуальные индикаторы активных бонусов
- Система приоритетов эффектов
